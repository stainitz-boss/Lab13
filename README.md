# Домашнее задание к работе 13: Структуры данных (Вариант 6)

## Условие задачи

> С одномерным массивом, состоящим из `n` вводимых с клавиатуры положительных и отрицательных целых чисел, выполнить следующие вычисления:
>
> 6. Среднее значение элементов массива, расположенных между первым и вторым отрицательными элементами.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Ввод `n`** — количества элементов массива.
3. **Ввод элементов массива:**
   * В цикле (`i` от 0 до `n-1`) запросить у пользователя целое число и сохранить в `arr[i]`.
4. **Поиск первых двух отрицательных элементов:**
   * Пройти по массиву слева направо.
   * Если элемент отрицательный (`arr[i] < 0`) и первое отрицательное ещё не найдено — запомнить его индекс в `first`.
   * Если первое уже найдено — запомнить индекс в `second` и прервать цикл (`break`).
5. **Проверка условий:**
   * Оба отрицательных найдены (`first != -1` и `second != -1`).
   * Между ними есть хотя бы один элемент (`second - first > 1`).
6. **Вычисление среднего:**
   * Просуммировать все элементы с индексами от `first + 1` до `second - 1`.
   * Подсчитать их количество.
   * Разделить сумму на количество.
7. **Вывод результата** (или сообщения о невозможности вычисления).
8. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>

int main() {
    int n, i;
    int arr[100];

    printf("Введите n: ");
    scanf("%d", &n);

    printf("Введите %d чисел:\n", n);
    for (i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    int first = -1, second = -1;

    for (i = 0; i < n; i++) {
        if (arr[i] < 0) {
            if (first == -1) {
                first = i;
            } else {
                second = i;
                break;
            }
        }
    }

    if (first != -1 && second != -1 && second - first > 1) {
        int sum = 0, count = 0;
        for (i = first + 1; i < second; i++) {
            sum += arr[i];
            count++;
        }
        printf("Среднее: %.2f\n", (float)sum / count);
    } else {
        printf("Нельзя вычислить\n");
    }

    return 0;
}
```
